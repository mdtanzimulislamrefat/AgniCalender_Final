1 · The problem

Satellites watched Bangladesh burn for 20 years — but the same fire was counted 2–5 times.

MODIS, VIIRS S-NPP and VIIRS NOAA-20 all see the same fire, at slightly different places and times, as several pixels. Counting pixels makes it look like burning explodes whenever a new satellite launches.

Fire managers need one consistent picture: when does burning really peak, and is this month unusual? Pixel counts cannot answer that.

2 · Why raw counts lie

VIIRS reports 3× as many detections as MODIS. There are not 3× as many fires.

3.06 : 1

VIIRS : MODIS raw detections, 2003–2024. VIIRS pixels are 375 m; MODIS pixels are ~1 km. VIIRS sees smaller fires MODIS misses.

2,862 → 7,411

Yearly events, 2012 → 2013, when VIIRS S-NPP arrived. Mostly new sensitivity — not proof burning tripled.

So the old AgniCalendar kept the sensors separate and said “do not compare them”. That is honest — and it is exactly what the challenge asks us to fix.

3 · The harmonization

Same fire, one event.

  • Vegetation fires only (FIRMS type 0). Static land (5,336) and offshore (1,107) counted separately, never hidden.
  • Same UTC date + within 1.0 km → one fire event, whatever sensor saw it. 1 km absorbs pixel / geolocation offset.
  • FRP is never summed across sensors — different pixel sizes. Max / median FRP is reported per sensor.
  • Climatology only where the sensor mix matches: 2019–2024, all three sensors. Earlier years get no anomaly rather than a misleading one.

Reproduce: python -m backend.processing.harmonize --years 2003-2024 --products modis,viirs-snpp,viirs-jpss1 · Method: backend/data/output/HARMONIZATION_METHOD.md

4 · The result

244,308 detections → 117,602 fire events.

2.08×

raw detections per harmonized event — 126,706 repeat detections merged away.

4,746

events in the peak month, April 2023 — from 18,685 raw detections.

7.4%

of events were seen by more than one sensor — an independent cross-check (8,680 events).

22 / 22

years whose peak month is March or April. The burning season is March–April, every year.
